# Identificador
Lector de Indicadores (`analizador.html`): sube grabaciones de pantalla, capturas o un HTML exportado (WhatsApp, reportes web) y obtén diagnóstico de indicadores financieros, plan de acción y rutina de seguimiento. Funciona publicado como Artifact en claude.ai (usa la capacidad `sample` para enviar los cuadros a Claude).
